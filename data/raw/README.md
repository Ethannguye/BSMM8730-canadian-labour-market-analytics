## Source Files

- 14100355-eng.zip: Original downloaded archive.

- 14100355_MetaData.csv: Accompanying CSV metadata.

The original source files are retained without modification.

## Intended Analysis Filters

These filters will be applied during data preparation:

- Reference period: January 2019–December 2025.
- Geography: The ten Canadian provinces.
- Statistics: Estimate.
- Data type: Seasonally adjusted.
- Employment unit: Persons in thousands.
- Industry selection: Non-overlapping categories documented
  during data preparation.

The full source archive contains observations outside
the project's analysis scope.
